# 📋 TodoList – Dupla

Este projeto é uma aplicação de Todo List desenvolvida em Java, utilizando Spring Boot no backend e JavaScript no frontend.
O sistema tem como objetivo permitir o gerenciamento de tarefas, servindo como prática de desenvolvimento full stack e integração entre frontend e backend por meio de uma API REST.

O projeto está sendo desenvolvido de forma incremental, com foco em aprendizado, organização do código e aplicação de conceitos do ecossistema Java.

Este projeto está sendo desenvolvido em dupla, por mim e por David.
